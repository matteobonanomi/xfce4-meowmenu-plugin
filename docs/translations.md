# Translation status

MeowMenu includes 56 gettext catalogs. Technical validity, translation
coverage, fallback behavior, and fluent review are separate properties. An
empty or unavailable translation uses the source English text. No language is
marked as fluent-reviewed until a maintainer records that review.

To improve a language, edit `po/<locale>.po`, run
`msgfmt --check po/<locale>.po`, and
[open a pull request](https://github.com/matteobonanomi/xfce4-meowmenu-plugin/pulls).
